## 概述

大嘴鱼（Big-mouth Fish）泛指中生代陆相地层中产出的原始真骨鱼类，因其**口裂大、头部宽阔**的形态特征而得名。这类鱼类化石在侏罗纪至白垩纪的湖相沉积中广泛分布，是中国陆相中生代地层中的重要化石类群。

原始真骨鱼类是硬骨鱼纲（Osteichthyes）中真骨鱼类（Teleostei）的早期代表，具有骨化的脊椎和鳞片，头部骨骼简化，口缘骨更具活动性，是现生鱼类（占现生鱼类 96%）的直接祖先或其近亲。

## 江津的大嘴鱼

江津**长江段及綦河流域**的侏罗系—白垩系红层中产出淡水鱼类化石，包括原始真骨鱼类。綦河是长江右岸一级支流，在江津境内切穿侏罗系沙溪庙组、遂宁组及白垩系夹关组红层，河床及沿岸露头中偶见鱼类化石碎片。

四川盆地中生代陆相沉积（"川中红层"）是中国陆相鱼化石的重要产地，产出狼鳍鱼（Lycoptera）、中华弓鳍鱼（Sinamia）等典型属。江津所在的**四川盆地东南缘**，湖相夹层中保存的鱼类化石是研究四川盆地中生代古湖泊生态系统的关键材料。

## 化石保存环境

大嘴鱼及其他淡水鱼类化石主要保存于：

1. **湖相页岩/泥岩**：静水湖盆环境，缺氧底水利于生物软体保存
2. **河流-三角洲相粉砂岩**：鱼类被快速埋藏
3. **泄湖相沉积**：周期性洪水带入湖盆

## 分类与特征

| 特征 | 说明 |
|------|------|
| **分类** | 硬骨鱼纲·真骨鱼类（Teleostei） |
| **体型** | 体长数厘米至数十厘米 |
| **鳞片** | 圆鳞或栉鳞，表面具生长纹 |
| **口部** | 口裂宽大，前颌骨可活动 |
| **尾鳍** | 正尾型，尾柄细 |

## 代表地点

- **重庆江津綦河流域**：侏罗系—白垩系红层中产出淡水鱼类化石
- **辽宁北票**：侏罗纪义县组狼鳍鱼群
- **山东莱阳**：白垩纪王氏组淡水鱼化石
- **四川自贡**：侏罗纪沙溪庙组鱼化石
