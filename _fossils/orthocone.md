## 概述

直角石（Orthocone）是直角石亚纲（Orthoceratoidea）头足动物的统称，以**直锥形或微弯**的外壳为最显著特征。"Orthocone"意为"直的圆锥"。直角石是古生代海洋中重要的游泳-浮游型掠食者，也是奥陶纪至三叠纪海相地层中的常见化石。

直角石的外壳由碳酸钙（CaCO₃）构成，内部被气室隔板分为多个气室。体管位于中央或近中央位置——这一点区别于菊石（体管位于外缘）和鹦鹉螺（体管位于中央或亚中央）。

## 江津的直角石

江津**南部奥陶系石灰岩**中产出直角石类头足动物化石，与四川盆地广泛分布的**奥陶纪海相沉积**一致。江津南部（四面山以南、中山镇周边）出露的奥陶系红花园组、湄潭组石灰岩代表了早—中奥陶世的浅海碳酸盐台地环境，是直角石等头足动物化石的富集层位。

四川盆地东南缘在奥陶纪处于**扬子地台西缘**，为温暖浅海环境，适宜头足动物繁盛。直角石与三叶虫、腕足类、笔石等伴生，共同构成典型的奥陶纪浅海底栖-游泳生物群落。

## 形态与结构

| 特征 | 说明 |
|------|------|
| **壳体形态** | 直锥形、圆柱形或微弯，横截面圆形至椭圆形 |
| **壳体长度** | 通常数厘米至数十厘米，大型者可达数米 |
| **气室** | 由隔板分隔，体管贯穿各气室 |
| **体管位置** | 中央至亚中央（区别于菊石的外缘体管） |
| **缝合线** | 简单，多为直线或微弯（区别于菊石的复杂缝合线） |
| **住室** | 壳体最前端的最后一个气室，容纳软体 |

## 演化与分类

直角石亚纲（Orthoceratoidea）是头足纲中演化历史最长、形态差异最大的类群之一：

- **出现**：奥陶纪早期（约4.8亿年前）
- **繁盛**：奥陶纪—志留纪
- **衰退**：泥盆纪后多样性大幅下降
- **灭绝**：三叠纪末

直角石被认为与**菊石**（Ammonoidea）和**蛸类**（Coleoidea，包括现生章鱼、乌贼）有较近的亲缘关系，可能是后两者的祖先类群之一。

## 代表地点

- **重庆江津南部**：奥陶系石灰岩中产出直角石化石
- **湖北宜昌**：奥陶纪直角石化石经典产地
- **湖南**：奥陶系石灰岩广泛产出
- **欧洲波罗的海地区**：奥陶纪直角石灰岩
