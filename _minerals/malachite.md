## 概述

孔雀石（Malachite）是一种**翠绿色**的碱式碳酸铜矿物，化学式为 **Cu₂CO₃(OH)₂**。因其颜色酷似孔雀羽毛的绿色而得名。孔雀石是最典型的**铜氧化带矿物**之一，常与**蓝铜矿**（Azurite, Cu₃(CO₃)₂(OH)₂）共生，两者合称"铜绿双璧"。

孔雀石以特征的**绿色条痕**、**盐酸反应起泡**和**同心层状构造**为重要鉴定标志。宝石级孔雀石具有美丽的同心环带和丝绢光泽，广泛用于制作珠宝和装饰品。

## 江津的孔雀石

江津南部**大圆洞及四面山岩溶区**的石灰岩中，含铜地下水在氧化带沉淀形成孔雀石，常与蓝铜矿共生。

### 成矿环境

大圆洞—四面山一带出露的寒武系—奥陶系石灰岩，在长期的喀斯特作用下发育了丰富的溶洞、溶蚀裂隙和地下暗河系统。当地下水循环流经含铜的围岩（如含铜页岩、含铜砂岩）时，铜离子（Cu²⁺）被溶解并随水迁移。当地下水进入喀斯特洞穴的**氧化环境**（氧气充足）并与石灰岩（CaCO₃）反应时，铜离子与碳酸根结合，沉淀为孔雀石：

$$2Cu^{2+} + 2CO_3^{2-} + 2OH^- \\rightarrow Cu_2CO_3(OH)_2 \\downarrow + CO_2 \\uparrow$$

### 与蓝铜矿的共生关系

孔雀石与蓝铜矿是经典的**矿物共生对**。在铜氧化带中，两者的沉淀受**CO₂分压**和**pH值**控制：蓝铜矿在较高 CO₂ 分压下稳定，孔雀石在较低 CO₂ 分压下稳定。在江津岩溶区，两者往往伴生产出，孔雀石呈翠绿色皮壳状附着在石灰岩裂隙面上，或与蓝铜矿交替形成美丽的蓝绿环带。

## 形成环境

孔雀石主要形成于铜矿床的**氧化带**（次生富集带）：

1. **原生铜硫化物氧化**：黄铜矿（CuFeS₂）等在地表氧化，释放 Cu²⁺
2. **铜离子迁移**：Cu²⁺ 在酸性溶液中向下渗透
3. **与碳酸盐反应**：遇到碳酸盐围岩（石灰岩、大理岩），沉淀为孔雀石

## 鉴定特征

| 特征 | 说明 |
|------|------|
| **颜色** | 翠绿色至深绿色，特征性强 |
| **条痕** | 淡绿色 |
| **光泽** | 丝绢光泽至玻璃光泽 |
| **硬度** | 3.5-4（可用小刀刻划） |
| **盐酸反应** | 滴稀盐酸起泡（区别于其他绿色矿物） |
| **构造** | 常呈肾状、葡萄状、钟乳状，具同心层状构造 |

## 用途

- **珠宝**：优质孔雀石用于制作项链、耳坠、胸针
- **颜料**：研磨为孔雀石绿，是古代重要的绿色矿物颜料
- **找矿标志**：孔雀石是寻找铜矿床的重要地表指示矿物

## 代表地点

- **重庆江津大圆洞岩溶区**：含铜地下水在石灰岩洞穴中沉淀孔雀石
- **广东阳春**：中国重要的孔雀石产地
- **湖北大冶**：铜绿山古铜矿遗址，孔雀石丰富
- **非洲刚果（金）**：世界最大的孔雀石产地
- **俄罗斯乌拉尔**：产出大型块状孔雀石
