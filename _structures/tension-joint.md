## 概述

张节理（Tension Joint）是岩石在**拉张应力**作用下形成的**张开型脆性破裂面**——裂隙垂直于张应力方向张开，两侧岩石向外分离，形成明显张开的裂缝。与剪节理不同，张节理面**粗糙不平直**，常被**石英脉**、**方解石脉**等矿物充填。

张节理在褶皱构造中具有规律的分布：集中于**背斜顶部**和**向斜核部**——因为褶皱弯曲时，外侧受拉伸（背斜顶部）或内侧受拉伸（向斜核部），是天然的"拉张区"。

在**重庆江津四面山**，白垩系夹关组（K₂j）红层在四川盆地—云贵高原过渡带的褶皱变形中，沿背斜轴部和褶皱转折端发育了密集的张节理。这些张节理部分被方解石脉或石英脉充填，构成了红砂岩中醒目的白色纹路——在丹霞赤壁上宛如天然的石刻笔画。

## 江津分布

### 四面山望乡台附近

望乡台瀑布及周边是观察张节理的最佳地点：

| 特征 | 说明 |
|------|------|
| **位置** | 四面山核心区，望乡台瀑布崖壁及周边露头 |
| **母岩** | 白垩系夹关组厚层红砂岩 |
| **节理产状** | 近垂直或陡倾斜 |
| **张开度** | 数毫米至数厘米 |
| **充填物** | 方解石脉（白色）、石英脉（乳白色）为主 |
| **发育部位** | 宽缓背斜轴部、岩层弯曲的拉伸区 |

站在望乡台附近，红色砂岩中纵横交错的白色方解石脉即是张节理的充填物——每一道白线都是一个被"愈合"的张裂面，记录了一次构造拉伸事件。

### 中山古镇周边

江津南部中山古镇至塘河一带的侏罗系—白垩系红层中，张节理广泛发育。部分大型张节理在后期被流水沿其扩大侵蚀，形成了中山古镇溪谷的初始轮廓——古镇吊脚楼沿张节理控制的溪谷排列，是构造与人文景观共生的范例。

### 水口寺峡谷

水口寺深切峡谷两侧崖壁上，张节理与剪节理共生——张节理为峡谷下切提供了初始的薄弱面，剪节理约束了峡谷的平面走向。

## 形成机制

### 拉张应力与破裂

张节理的形成条件是：**最小主应力 σ₃ 为拉张应力**（负值），且其绝对值超过岩石的**抗拉强度**（T₀）。岩石的抗拉强度通常远低于抗压强度（约为抗压强度的 1/10 至 1/30），因此拉张破裂在岩石中相对容易发生。

### 褶皱中的张节理

在褶皱弯曲过程中，岩层的外弧（背斜顶部）受拉伸、内弧受挤压：

- **背斜顶部**：岩层向上弯曲，顶部外侧受拉张——形成**纵张节理**（平行于褶皱轴）和**横张节理**（垂直于褶皱轴）
- **向斜核部**：岩层向下弯曲，核部内侧受拉张——同样发育张节理

四面山所在的川黔过渡带发育了一系列宽缓褶皱（川东隔档式褶皱的南延），张节理在褶皱轴部集中出现。望乡台正处于一个宽缓背斜的轴部位置，因此张节理特别发育。

### 充填作用

张节理张开后，地下水中的溶解矿物（CaCO₃、SiO₂）沿裂隙渗透并沉淀结晶：

1. 构造拉伸 → 裂隙张开 → 空隙压力降低 → 地下水被"吸入"裂隙
2. 矿物过饱和 → CaCO₃（方解石）或 SiO₂（石英）在裂隙壁上结晶
3. 长期持续 → 裂隙被完全充填 → "愈合"的张节理

充填脉的宽度可以反映张节理的总张开量，是定量估算构造拉伸量的重要依据。

## 张节理 vs 剪节理

| 特征 | 张节理 | 剪节理 |
|------|--------|--------|
| **力学性质** | 拉张 | 剪切 |
| **节理面** | 粗糙、不平直 | 光滑、平直，常有擦痕 |
| **排列** | 一组平行，沿张应力方向排列 | 两组共轭，X形交叉 |
| **张开度** | 明显张开 | 闭合或微张 |
| **充填物** | 常被石英脉、方解石脉充填 | 偶有石英/方解石薄膜 |
| **发育部位** | 褶皱轴部（背斜顶、向斜核） | 均匀分布，无特定构造部位 |
| **应力指示** | 节理面⟂→σ₃（张应力方向） | 锐角平分线→σ₁ |
| **江津代表** | 望乡台周边 | 土地岩X型节理 |

## 野外识别

在四面山野外如何识别张节理：

1. **看充填**：是否有白色石英脉或方解石脉充填——这是张节理最显著的标志
2. **看表面**：用手指触摸节理面——张节理面粗糙，有砂粒感；剪节理面光滑
3. **看排列**：张节理通常为一组近平行排列，无X形交叉
4. **看位置**：是否位于褶皱的轴部或转折端——张节理在这些部位集中
5. **看张开度**：张节理多有肉眼可见的张开，剪节理常闭合

## 张节理的地貌与水文学意义

四面山张节理的地质作用远超构造记录本身：

### 地貌控制

- **峡谷初始薄弱面**：溪流优先沿张节理面下切——水口寺峡谷的形成即受张节理控制
- **崖壁崩塌边界**：张节理与剪节理交切，将崖壁切割为独立块体，崩塌沿节理面发生

### 水文通道

- **地下水渗流**：张节理的张开特性使其成为地下水的主要渗流通道——江津充沛的降水（1,000–1,200 mm/年）沿张节理快速下渗
- **泉水出露**：部分岩溶泉沿张节理面出露——大圆洞及四面山的泉水多与此有关

### 成矿指示

- **方解石脉**反映碳酸钙饱和的地下水活动——可能与邻区岩溶水的侧向运移有关
- **石英脉**反映二氧化硅饱和的热液或地下水活动——温度可能高于常温

## 张节理与丹霞地貌演化

四面山的丹霞赤壁地貌演化中，张节理扮演了"先锋"角色：

1. **初始破裂**：构造拉伸形成张节理 → 岩体完整性被破坏
2. **沿节理风化**：水沿张节理下渗 → 化学风化加速 → 裂隙加宽
3. **流水切入**：地表径流沿张节理集中 → 下切形成溪谷
4. **崖壁后退**：张节理面成为崩塌边界 → 崖壁沿节理后退
5. **石柱孤立**：两组张节理交切 → 石柱从崖壁分离 → 石鼓/飞来石的雏形

> 张节理是丹霞地貌演化的"起跑线"——没有构造拉伸在先，就没有后来流水侵蚀的精雕细琢。

## 构造地质学意义

四面山红层中的张节理系统记录了川黔过渡带新生代构造拉伸事件，为以下科学问题提供了关键证据：

- **川东南宽缓褶皱的变形机制**：张节理集中发育于褶皱轴部，验证了弯曲-拉伸的经典模型
- **区域应力场的时空演化**：从挤压（形成褶皱）→ 局部拉伸（褶皱顶部张节理）→ 再次挤压（剪节理切割张节理），记录了多期应力场的转换
- **古应力大小估算**：通过充填脉的宽度和矿物类型，可定量约束张节理形成时的差应力水平
