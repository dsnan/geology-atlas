## 概述

剪节理（Shear Joint）是岩石在**剪切应力**作用下沿最大剪应力方向形成的**脆性破裂面**，两侧岩石沿节理面发生微小的剪切位移（无明显法向张开）。剪节理最典型的特征是常以**两组共轭**的形式出现——两组节理呈 **X 形**交叉，锐角平分线指示最大主压应力（σ₁）方向。

剪节理是**构造应力场的"化石"**——通过测量共轭剪节理的产状和夹角，可以反演节理形成时的古应力方向。这一方法在构造地质学中应用极为广泛。

在**重庆江津四面山**，白垩系夹关组（K₂j）厚层红砂岩中广泛发育了X型共轭剪节理，尤其在土地岩丹霞崖壁、水口寺峡谷和望乡台周边的露头上清晰可见。这些剪节理形成于新生代四川盆地—云贵高原过渡带的构造挤压事件，其排列方向系统地记录了区域应力场特征。

## 江津分布

### 四面山土地岩崖壁

土地岩的赤壁丹崖是观察剪节理的最佳天然剖面：

| 特征 | 说明 |
|------|------|
| **位置** | 四面山核心区，土地岩丹霞崖壁 |
| **母岩** | 白垩系夹关组厚层红砂岩 |
| **节理组数** | 两组共轭剪节理 |
| **走向** | NNE 和 NW 向 |
| **交角** | 约 60°（锐角平分线近 E-W 向） |
| **节理面特征** | 光滑平直，局部见擦痕 |
| **充填情况** | 部分被石英细脉或方解石脉充填 |

站在土地岩崖壁前，两组平行延伸的节理线在红色砂岩面上交织成规则的X形网格——这是应力场在岩石中留下的最直观的"笔迹"。

### 水口寺峡谷

水口寺深切峡谷的两侧崖壁上，剪节理的X形图案尤为壮观——峡谷本身就是沿一组剪节理面优先下切形成的。

### 望乡台周边

望乡台瀑布崖壁及周边露头上，剪节理密集发育，部分节理面被后期溶蚀扩大为崖壁凹槽和岩洞。

### 中山古镇—塘河沿线

江津南部中山古镇至塘河一带的侏罗系—白垩系红层中，同样发育剪节理，表明区域构造应力场影响范围广阔。

## 形成机制

### 摩尔-库仑破裂准则

剪节理的形成遵循**摩尔-库仑破裂准则**（Mohr-Coulomb Failure Criterion）：当岩石中某一面上的剪应力 τ 超过岩石的内聚力 C 与内摩擦阻力 μσₙ 之和时，沿该面发生剪切破裂：

**τ ≥ C + μσₙ**

其中 σₙ 为作用于该面上的正应力，μ 为内摩擦系数。

### 共轭剪节理的应力解释

在水平最大主压应力（σ₁）和水平最小主压应力（σ₃）的共同作用下：

- 两组剪节理沿**两个共轭的最大剪应力面**形成
- 两组节理的**锐角平分线**指示 σ₁ 方向
- 两组节理的**钝角平分线**指示 σ₃ 方向

四面山土地岩的共轭剪节理锐角平分线近 E-W 向，说明节理形成时的最大主压应力（σ₁）方向为近东西向——这与新生代青藏高原东缘向四川盆地传递的挤压应力方向一致。

### 江津的区域应力场

江津处于**四川盆地与云贵高原过渡带**，新生代以来经历了多期构造挤压：

1. **早新生代**：印度-欧亚板块碰撞的远程效应——E-W 向挤压
2. **晚新生代**：云贵高原加速抬升——SE-NW 向挤压分量叠加

四面山红层中的剪节理系统记录了这两期应力场的叠加，是研究**青藏高原东南缘远程构造效应**的宝贵窗口。

## 剪节理 vs 张节理

| 特征 | 剪节理 | 张节理 |
|------|--------|--------|
| **力学性质** | 剪切 | 拉张 |
| **节理面** | 光滑、平直，常有擦痕 | 粗糙、不平直，无擦痕 |
| **排列** | 两组共轭，X形交叉 | 一组平行，沿张应力方向排列 |
| **张开度** | 闭合或微张 | 明显张开 |
| **充填物** | 偶有石英/方解石薄膜 | 常被石英脉、方解石脉充填 |
| **应力指示** | 锐角平分线→σ₁ | 节理面⟂→σ₃（张应力方向） |
| **江津代表** | 土地岩X型节理 | 望乡台周边张节理 |

## 野外识别

在四面山野外如何识别剪节理：

1. **看排列**：是否有两组节理呈X形交叉——这是最直观的标志
2. **看节理面**：剪节理面光滑平直，用手指触摸有光滑感；张节理面粗糙
3. **看擦痕**：剪节理面上有时可见细小的滑动擦痕（擦痕线理）
4. **看充填**：剪节理通常不被厚脉充填（闭合为主），张节理常有石英/方解石脉
5. **测产状**：测量两组节理的走向、倾向、倾角，计算夹角

## 剪节理的地貌控制意义

四面山剪节理不仅是构造应力场的记录，还深刻控制着丹霞地貌的发育：

- **峡谷方向**：一线天和V形谷优先沿剪节理方向发育
- **崖壁形态**：赤壁丹崖的平面形态受两组剪节理交切控制，形成锯齿状崖线
- **崩塌边界**：岩块的崩塌面往往是剪节理面——崩塌后的崖壁仍然平整如削
- **瀑布位置**：水流沿节理交叉点集中下切，控制了瀑布的发育位置

> 四面山的丹霞景观 = 红层（物质基础）× 剪节理（构造框架）× 降水（侵蚀动力）——剪节理提供了地貌发育的"蓝图"。

## 构造地质学意义

四面山红层中的剪节理系统为研究以下科学问题提供了天然实验室：

- **川东南新生代构造应力场演化**：通过统计节理产状重建古应力方向
- **青藏高原东缘远程效应**：验证高原隆升对四川盆地边缘的挤压传递
- **红层构造与丹霞地貌的耦合关系**：构造框架如何控制侵蚀地貌的发育方向
