## 概述

喀斯特溶洞（Karst Cave）是地下水对可溶性岩石（主要是石灰岩）进行化学溶蚀形成的地下空间系统。喀斯特（Karst）一词来源于斯洛文尼亚的喀斯特高原，中文又称"岩溶"。

## 形成过程

喀斯特溶洞的形成需要四个基本条件：
1. **可溶性岩石**：主要为石灰岩（CaCO₃），其次为白云岩、石膏
2. **水**：丰富的降水和地下水循环
3. **CO₂**：大气和土壤中的 CO₂ 溶于水形成碳酸（H₂CO₃）
4. **时间**：需要数十万至数百万年

化学反应：CaCO₃ + H₂CO₃ → Ca(HCO₃)₂（可溶性碳酸氢钙）

## 溶洞次生沉积物

当富含 Ca²⁺ 和 HCO₃⁻ 的地下水进入溶洞空间时，CO₂ 逸出导致 CaCO₃ 沉淀：

| 类型 | 特征 |
|------|------|
| **钟乳石 (Stalactite)** | 从洞顶向下生长 |
| **石笋 (Stalagmite)** | 从地面向上生长 |
| **石柱 (Column)** | 钟乳石与石笋相接 |
| **石幔 (Curtain)** | 沿洞壁流下的薄层沉淀 |
| **边石坝** | 阶梯状钙华坝 |

## 世界著名喀斯特溶洞

- **贵州织金洞**：中国最大
- **重庆武隆芙蓉洞**：世界自然遗产
- **越南韩松洞**：世界最大的单体溶洞
- **美国猛犸洞**：世界最长的溶洞系统（>640 km）

## 科学价值

- **古气候记录**：钟乳石的年层和氧同位素可重建古气候
- **古人类学**：许多溶洞保存了古人类化石（如周口店北京猿人）
- **考古学**：溶洞常是古代人类居住场所
