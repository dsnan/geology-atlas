## 概述

一线天（Slot Canyon / Narrow Gorge，又称嶂谷）是峡谷地貌的一种极端形态——河流沿**垂直节理**强烈下切，形成**极窄极深**的谷道，在谷底仰望上空，仅见**一线天光**，故得名。

一线天的本质是**V形谷的极限版**：当河流下切速率远大于侧蚀速率，且岩体中存在密集的**垂直节理**约束谷壁的展宽时，峡谷在两壁几乎平行的夹峙中向下深切，形成深宽比极大的嶂谷。

在**重庆江津四面山**，一线天是丹霞地貌序列中最震撼的景观之一。白垩系夹关组（K₂j）厚层红砂岩在四川盆地—云贵高原过渡带的构造应力作用下，发育了两组近垂直的密集节理。充沛的亚热带降水（年均 1,000–1,200 mm）沿节理面下渗和地表径流沿节理线下切，将红层切割出了多条经典的一线天景观。

## 江津分布

### 四面山水口寺一线天

水口寺一线天是江津最典型的一线天景观：

| 特征 | 说明 |
|------|------|
| **位置** | 四面山核心区，水口寺峡谷 |
| **岩性** | 白垩系夹关组厚层红砂岩 |
| **谷深** | 近百米 |
| **谷宽** | 最窄处仅 2–3 米 |
| **深宽比** | 极高，典型嶂谷 |
| **控制构造** | 两组近垂直节理（走向 NNE 和 NW） |
| **伴生景观** | 水口寺瀑布从一线天崖顶飞泻 |

> 站在水口寺谷底仰望，红色砂岩崖壁高耸近百米，两侧崖壁近乎平行夹峙，天空被压缩成一条蜿蜒的亮线——这就是"一线天"三个字的全部含义。

### 四面山飞龙庙一线天

洪海湖畔飞龙庙附近亦发育有一线天景观，规模较水口寺略小，但谷底溪流潺潺，植被茂密，更具幽深感。

### 其他小型一线天

四面山珍珠溪、土地岩等地的溪流，在沿节理下切的幼年期阶段，也呈现局部的一线天形态——狭窄、幽深、两岸崖壁近乎垂直。

## 形成机制

四面山一线天的形成是**构造**与**侵蚀**精确配合的结果：

### 1. 构造打底——垂直节理

江津处于**四川盆地与云贵高原过渡带**，新生代以来云贵高原的持续抬升向四川盆地传递挤压应力，使白垩系红层中发育了密集的**垂直节理**。两组近正交的节理（NNE 向和 NW 向）将厚层砂岩切割为规则的块体，为一线天提供了"天然导流槽"。

### 2. 河流沿节理下切

地表径流优先沿节理线汇聚——节理面是岩石中最薄弱的"裂缝"，水流沿其向下侵蚀远比在完整岩石中容易。当河流的下切速率远大于侧蚀速率时，峡谷在保持极窄宽度的同时不断加深。

### 3. 差异风化辅助

红层中**软硬相间**的岩性组合（硬砂岩 vs 软泥质砂岩）使得：
- **硬层**维持崖壁的垂直形态
- **软层**被选择性风化剥蚀，形成崖壁上的凹槽和岩洞

### 4. 重力崩塌维持陡壁

崖脚软层被掏蚀后，上方硬砂岩悬空，在节理面控制下发生**块状崩塌**——崩塌面恰好是节理面，因此崩塌后的崖壁仍然是近乎垂直的，维持了一线天的狭窄形态。

### 5. 气候驱动

江津**亚热带湿润季风气候**提供了丰沛的降水——年均 1,000–1,200 mm 的降雨量和年均 18°C+ 的气温，使得化学风化（钙质胶结物溶解）和物理侵蚀同时高效进行。

## 一线天 vs V形谷 vs 峡谷

| 特征 | 一线天（嶂谷） | V形谷 | 峡谷（广义） |
|------|---------------|-------|-------------|
| **谷宽** | 极窄（数米） | 窄（数十米） | 宽窄不一 |
| **深宽比** | 极高 | 高 | 中等—高 |
| **谷壁** | 近乎平行，垂直 | V 形张开 | 多样 |
| **发育阶段** | 幼年期（下切主导） | 幼年—壮年期 | 各阶段均可 |
| **节理控制** | 极强 | 中等 | 弱—中等 |
| **江津实例** | 水口寺一线天 | 綦河峡谷 | 猫儿峡 |

## 一线天与丹霞地貌

四面山的一线天是**丹霞地貌**的组成部分。丹霞区的垂直节理为一线天的发育提供了精确的构造框架，而丹霞赤壁则提供了极具视觉冲击力的红色崖壁背景。水口寺的一线天——红色砂岩崖壁 + 一线天光 + 飞瀑直下——是"丹霞一线天"的经典组合。

> 如果说丹霞赤壁展现的是"宽度"的壮丽，那一线天展现的就是"窄度"的极致——同一种红层，不同的侵蚀方向，演绎出截然不同的地貌美学。

## 一线天的水文意义

一线天的狭窄形态使其成为观察**河流幼年期下切过程**的天然剖面。谷底基岩裸露、跌水不断、几无河漫滩——这些特征说明河流几乎将全部能量用于向下侵蚀，侧蚀几乎为零。四面山的一线天为研究**川东南低山区河流下切速率**和**构造抬升—侵蚀响应关系**提供了理想野外实验室。
