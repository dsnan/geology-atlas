## 概述

安山岩（Andesite）是一类**中性火山喷出岩**，SiO₂含量在 **52-63%** 之间，介于基性玄武岩（45-52%）和酸性流纹岩（>63%）之间。安山岩因南美**安第斯山脉**（Andes）大量产出而得名，是汇聚板块边界（俯冲带）火山弧的标志性岩石。

安山岩通常呈**斑状结构**——斑晶为斜长石、角闪石、辉石或黑云母，基质为隐晶质至玻璃质。颜色以灰色、灰绿色、紫红色为主。气孔构造和杏仁构造常见，气孔被后期矿物（方解石、石英、绿泥石等）充填即形成杏仁体。

## 江津的安山岩

江津南部**中山镇—四面山**一带出露的侏罗系火山岩夹层中含有安山岩，是**四川盆地东南缘中生代火山活动**的遗迹。

### 地质背景

四川盆地东南缘在中生代（侏罗纪—白垩纪）存在间歇性火山活动，作为华南板块与华北板块碰撞后陆内伸展环境的响应。火山岩以**夹层**形式赋存于厚层陆相红层（沙溪庙组、遂宁组）中，单层厚度从数十厘米到数米不等，横向延伸有限——这是典型的大陆内部小型火山喷发的产物。

江津中山镇周边出露的火山岩夹层中，安山岩呈灰绿色至紫红色，斑状结构明显，斑晶以斜长石为主（自形—半自形板状），含少量暗色矿物（辉石、角闪石）。这些火山岩夹层为研究四川盆地中生代构造—岩浆演化提供了珍贵的物质记录。

### 中山镇火山岩露头

中山镇—四面山旅游公路沿线，零星可见侏罗系红层中的火山岩夹层，野外识别标志包括：
- 颜色突变：红层中出现灰绿色或紫红色条带
- 致密坚硬：较围岩（泥岩、粉砂岩）明显坚硬，抗风化
- 斑状结构：肉眼可见长石斑晶

## 形成过程

安山岩的形成与**俯冲带**密切相关：

1. **俯冲板片脱水**：大洋板块俯冲到大陆板块之下，含水矿物脱水
2. **地幔楔部分熔融**：水进入上覆地幔楔，降低岩石熔点，产生玄武质岩浆
3. **结晶分异与同化混染**：玄武质岩浆上升过程中发生结晶分异，或同化混染地壳物质，成分向酸性演化
4. **喷发冷却**：安山质岩浆喷出地表，快速冷却

在江津中生代陆内环境，安山岩的形成机制可能涉及**大陆裂谷/伸展环境**下地幔上涌导致的岩浆活动。

## 鉴定特征

| 特征 | 说明 |
|------|------|
| **颜色** | 灰色、灰绿色、紫红色 |
| **结构** | 斑状结构，斑晶为斜长石和暗色矿物 |
| **SiO₂** | 52-63%（中性岩） |
| **产状** | 熔岩流、火山碎屑岩，或夹层于沉积岩中 |

## 分布

- **重庆江津中山镇**：侏罗系红层中安山岩夹层
- **安第斯山脉**：世界最典型的安山岩分布区（安山岩命名地）
- **日本、印尼、菲律宾**：岛弧安山岩
- **中国东北**：中生代火山岩区安山岩

## 经济意义

安山岩坚硬致密，是优良的建筑石材和路基材料。在江津中山镇一带，当地居民传统上利用安山岩坚硬的特点建筑石坎和地基。
